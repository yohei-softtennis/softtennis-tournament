# ソフトテニス大会進行表（独立Webサービス版）

ソフトテニス大会の進行表をWebで公開・運営するための小さなアプリです。
Node.js の標準機能だけで動き、外部パッケージ（npm install）は不要です。
データは同じフォルダの `data.json` に保存されます（初回起動時に自動生成）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `server.js` | サーバー本体（API・画面配信・順位計算などのロジックすべて） |
| `data.json` | 保存データ（パスワードのハッシュと大会データ）。初回起動時に自動生成 |
| `README.md` | このファイル |

## 起動方法

```bash
node server.js
```

- ポートは環境変数 `PORT` があればそれ、なければ `3000` を使います。
  例: `PORT=8080 node server.js`
- 起動したらブラウザで開きます。
  - 閲覧ページ: `http://localhost:3000/`
  - 管理者ページ: `http://localhost:3000/admin`
- 管理者ページの初回アクセス時に、管理者パスワードを設定します。
  以後はパスワードを知っている人だけが管理者ページに入れます
  （編集系APIはすべてサーバー側でパスワード照合します）。

## 使い方

1. 管理者ページで大会を作成（大会名／方式／参加ペア数など）。
   - 方式は「トーナメントのみ」「リーグ戦 → トーナメント」から選べます。
   - リーグ方式では「1リーグのペア数」「トーナメント進出数（各リーグ上位Nペア）」も設定できます。
2. 参加ペアを登録（ペア名・所属・強者フラグ）。
3. 「ランダム割り振り」で自動配置（同所属を離す／強者を離すルールはON/OFF可）。
   割り振り後はペアをタップ（クリック）して手動で入れ替え・移動もできます。
   トーナメント方式でペア数が2の累乗でない場合は、不戦勝（BYE）枠が自動で付き、
   BYEの相手は自動で次戦へ進みます。
4. 試合ごとにゲームスコア（例：3-0）を入力するだけ。勝敗は自動判定です。
   - リーグは順位を自動計算（勝数 → 得失ゲーム差 → 得ゲーム数 → 直接対決）し、
     上位ペアがトーナメント表へ自動で入ります（途中結果でも暫定順位で反映）。
   - トーナメントは勝者が自動で次戦へ進出します。
5. 閲覧ページは読み取り専用で、30秒ごとに自動更新されます。
   参加者・保護者には閲覧ページのURLだけを共有してください。

## データの初期化

- 大会だけ消す: 管理者ページの「大会を削除する」。
- すべて初期化する: サーバーを止めて `data.json` を削除し、再起動してください
  （パスワードも含めて初期状態に戻ります）。

## デプロイ先の候補（メモ）

`node server.js` が動く場所ならどこでも置けます。無料枠のある候補:

- **Render**（Web Service）: GitHub連携でデプロイ。無料枠あり（スリープあり）。
  Start Command は `node server.js`、環境変数 `PORT` は自動で渡されます。
- **Railway**: GitHub連携でデプロイ。無料トライアルあり。`node server.js` で起動。
- **Fly.io**: `fly launch` でNodeアプリとしてデプロイ可能。
- **VPS（さくら・ConoHa・AWS Lightsail など）**: 月数百円〜。
  `node server.js` を systemd や pm2 で常駐させ、必要に応じてリバースプロキシ
  （nginx等）＋独自ドメイン＋HTTPSを設定します。
- **自宅/会場PC**: 同じネットワーク内だけの公開なら、PCで起動して
  そのPCのIPアドレス＋ポートを共有するだけでも使えます。

注意点:

- `data.json` に全データが入ります。ホスティング先では永続ディスク
  （Persistent Disk等）をマウントしたフォルダにアプリを置くか、
  再デプロイでデータが消える仕様でないかを確認してください。
- 公開する場合は HTTPS 化し、管理者パスワードは推測されにくいものにしてください。
- 選手名などの個人情報を公開ページに載せるため、公開範囲にはご注意ください。
